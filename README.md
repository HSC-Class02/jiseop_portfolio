# 신지섭 포트폴리오

블루 메인 컬러와 하늘색 배경을 적용한 반응형 단일 페이지 포트폴리오입니다.

## Category
- **About**: 소개 및 프로필
- **AI-Generated Reports**: 딥노이드 OpenDART 대시보드와 2023–2024 핵심 재무 분석
- **Qualifications & Certifications**: Coursera 수료증 1건 (원본 PDF)
- **Activities**: 프로젝트·학습·교내외 활동

## Deploy
GitHub Pages에서 `main` 브랜치의 `/ (root)`를 배포 소스로 선택하면 됩니다.

## 확인 후 교체할 항목
- GitHub 및 LinkedIn 프로필 URL은 현재 임시 링크(`your-id`)입니다.
- About의 학력·경력·기술 항목과 Activities의 실제 활동 이력은 CV 및 활동 내역 확인 후 업데이트해야 합니다.
- 프로필 이미지는 개인 사진을 임의로 넣지 않고 심볼형 아바타로 구성했습니다.
